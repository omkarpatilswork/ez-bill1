# AGENTS.md

## Technical decisions

- Client-side PDF export (e.g. Monthly Summary page) uses `html2canvas-pro` + `jspdf`: capture the summary container at scale 2 on a dark background, slice the canvas into A4 pages. `html2canvas-pro` (not plain `html2canvas`) is required because the theme uses `oklch`/modern color functions.
- Monthly Summary must count ALL of the user's bills, including `status: 'draft'` rows — draft is the normal status for every auto-imported bill (Gmail scan, bulk upload, OCR quick-save, NFC claim) and the rest of the app (All Bills, Analytics, Money Leaks) treats drafts as real bills. Never filter drafts out of money totals again.
- Shared broad-category mapping exists in `src/components/bills/BillRow.tsx`, `src/pages/expenses/MyExpenses.tsx` and `src/pages/MonthlySummary.tsx`; when changing category buckets, update all three. The redesigned screens (`src/pages/next/`) read the same buckets from `src/lib/bill-category.ts`: keep it in step with the other three until they are moved onto it.
- Monthly income has no transactional source; it is estimated from `profiles.income_range` via `incomeMidpoint()` (`src/lib/leak-engine.ts`) and labeled "Est. from profile". When no income is set, show a prompt to set it in Profile instead of a default value.
- Money Leaks ideal budget comes from `computeIdealBudget()` (`src/lib/leak-engine.ts`): rent + EMI (`monthly_rent`/`monthly_emi`) are carved out first (capped at 60% of income), then discretionary spend is budgeted by goal. Home's leak card (`src/pages/next/Home.tsx`) uses the same engine and the same inputs; keep both fed by this one function. With no money profile, Home shows a prompt, never a guessed number.
- Redesigned screens ("Ink & Paper") live in `src/pages/next/` and `src/components/next/` and use only the `ez-*` classes and the `surface`/`line`/`fg`/`dim`/`faint`/`brand`/`gilt`/`leak`/`paper` Tailwind colours from `src/styles/ink.css`. Do not use the old shadcn tokens (`bg-background`, `text-gold`, `glass-card`...) in them, and do not use the new tokens in screens that have not been redesigned.
- New screens read the packed `expenses.description` format (`::ITEMS::`, `Invoice:`, `[nfc]`...) only through `src/lib/bill-format.ts`. Do not add another parser.
